# Mergepay Docs

Mergepay is a Stellar-native group settlement app — split expenses, settle
with real on-chain Stellar payments, see the transaction hash instead of
taking someone's word for it.

- New here? Start with [What is Mergepay](introduction/what-is-mergepay.md).
- Using the app? Go to [For Group Members](for-group-members/getting-started.md)
  or [For Treasury Admins](for-treasury-admins/getting-started.md).
- Building or contributing? Go to the [Developer Guide](developer-guide/local-setup.md)
  and [How to Contribute](contributing/how-to-contribute.md).
